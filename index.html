Pixel Borregos es un grupo estudiantil del Tec de Monterrey cuyo objetivo es el desarrollo de un video juego hecho solamente por estudiantes. Este grupo consiste en un equipo multidisciplinario de toda la universidad que va de artistas digitales, hasta ingenieros de sonido para crear efectos de sonido. Actualmente actúo como el director de programación donde desarrollamos las diferentes mecánicas, enemigos e interacciones del juego. Este proyecto se está desarrollando usando Unity y programando en C#. También tengo la responsabilidad de gestionar tiempos y manejar tareas para cada miembro de mi equipo para poder cumplir con las metas que nos hemos puesto.
